# アソビ大全トーナメント

BBQ後の余興用トーナメントアプリです。

## 機能

- 参加者名を入力してランダムにトーナメント作成
- 奇数人数の場合はランダムにシードを自動付与
- 各対戦の勝者をタップして次ラウンドへ反映
- 食材費合計から参加人数分の平均金額を表示
- 勝者の支払い金額/敗者の支払い金額を入力して順位に応じた傾斜配分を自動計算
- 同率あり/同率なしの順位モード切替
- 同率なしでは決勝後に敗者同士の順位決定戦を自動生成し、全員の順位を確定
- 決勝完了後に結果と支払い一覧へ自動スクロール
- ストップ後に減速して止まるルーレット演出
- 世界のアソビ大全51の収録ゲーム候補からルーレットで対戦ゲームを決定

## 使い方

`index.html` をブラウザで開くだけで動きます。

GitHub Pages では `main` ブランチのルートを公開対象にしてください。
